# حالة الشاشات ومتطلباتها (SCREENS)

يتم تحديث هذا الملف مع كل مرحلة. لا يبدأ العمل في شاشة جديدة إلا بعد اعتماد المستخدم للشاشة الحالية.

| المرحلة | الشاشة / المكوّن | الحالة | الحالات المغطاة (Normal / Loading / Empty / Error / Offline) | الصلاحيات المفروضة |
| :--- | :--- | :--- | :--- | :--- |
| **1** | **الأساس (الداتابيز + المراحل السبع + الأدوار)** | **قيد المراجعة والاعتماد** | شريط محاكاة تفاعلي كامل + تبديل المراحل 1..7 | RLS كامل على كل جدول + منع تعديل `points_ledger` و `audit_log` |
| **2.أ** | **شاشة الدخول بالكود (المشاركون + فريق العمل + الأدمن)** | **قيد المراجعة والاعتماد** | عادي، تحميل، خطأ كود/تجاوز محاولات، حساب قيد الانتظار، أوفلاين | التحقق من `code_hash` + كلمة مرور الأدمن + التحقق من `status = approved` |
| **2.ب** | **شاشة تسجيل خادم جديد (`Register Servant`)** | **قيد المراجعة والاعتماد** | عادي، تحميل، قفل المرحلة (مفتوح في المراحل 1-3 فقط)، خطأ تحقق، أوفلاين | متاح فقط في المراحل 1 إلى 3، ينشئ الحساب بحالة `pending` ويولّد `qr_token` منفصل عن الكود |
| **2.ج** | **شاشة الاسترجاع بالرقم القومي (`Recover by National ID`)** | **قيد المراجعة والاعتماد** | عادي، تحميل، تجاوز حد المحاولات، إرسال للإيميل، تحويل للأدمن عبر واتساب | لا يعرض الكود على الشاشة أبداً، يبحث بـ `national_id_hash` ويسجل في `audit_log` |
| **3** | شاشة الأدمن (المحتوى، المحاور، الفعاليات، سياسة الحضور) | لم تبدأ (بانتظار اعتماد المرحلة 2) | - | `admin` فقط |
| **4** | اعتماد الخدام بالجملة وتعيين الأدوار | لم تبدأ | - | `admin` + `service_lead` (لخدمته فقط) |
| **5** | إدخال المخدومين (الخادم المسجِّل) | لم تبدأ | - | `registrar` (لخدمته، وفي المرحلة 4 فقط) |
| **6** | قفل التسجيل وتقسيم الفرق | لم تبدأ | - | `service_lead` (في المرحلة 5 و6) |
| **7** | إصدار البطاقات والـ QR (PDF للطباعة) | لم تبدأ | - | `admin` + `service_lead` (المرحلة 6) |
| **8** | المسح والحضور والأوفلاين وحضور البوابة | لم تبدأ | - | `staff` + `admin` (المرحلة 7) |
| **9** | النقاط وشاشة مسؤول الفريق وتقييم التفاعل | لم تبدأ | - | `team_lead` (لفريقه) + `staff` |
| **10** | البونص ونقاط الألعاب | لم تبدأ | - | `staff` (لمحطته وجولاته) |
| **11** | الطوارئ والمفقودات وبلاغ فريق بدون خادم | لم تبدأ | - | كل الخدام للإبلاغ + `emergency` / `service_lead` للاستلام |
| **12** | شاشة العرض العامة بالتوكن (Kiosk) | لم تبدأ | - | توكن قراءة فقط مجزأ (`token_hash`) |
| **13** | التقارير والتصدير وعلامات المراجعة | لم تبدأ | - | `admin` |
| **14** | اختبار التحميل والبروفة الكاملة | لم تبدأ | - | `admin` |
