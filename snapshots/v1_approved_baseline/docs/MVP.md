# نطاق النسخة الأولى (MVP) - كرنفال الأطفال 2027

النسخة الأولى هدفها يوم **السبت 30 يناير 2027** فقط. أي ميزة خارج عمود "جوه الـ MVP" تتأجل لما بعد الكرنفال.

| جوه الـ MVP (معتمد للتنفيذ) | برا الـ MVP (مؤجل لما بعد الكرنفال) |
| :--- | :--- |
| دخول الخدام بالكود، وتسجيل الخادم واعتماده | طرق دخول تانية (جوجل أو غيره) |
| تسجيل المخدومين، وقفل التسجيل، وتقسيم الفرق | استيراد المخدومين من ملف Excel |
| بطاقات QR بكود مطبوع (PDF للطباعة) | إرسال الكروت لأولياء الأمور أوتوماتيك |
| حضور البوابة وحضور الفعاليات، مع الأوفلاين | تطبيق موبايل منفصل (الـ PWA كفاية) |
| النقاط: حضور، بونص، مشاركة، ألعاب، تقييم تفاعل متاح مع الأوفلاين ويتم رفع أيهما أحدث مع الأونلاين من نفس الخادم المسؤول | اعتراض المشارك على النقاط |
| شاشة مسؤول الفريق (نقاط كل طفل ومجموع الفريق) | تقارير متقدمة وتحليلات (التصدير البسيط جوه) |
| الطوارئ والمفقودات وبلاغ فريق بدون خادم | إشعارات Push |
| شاشة العرض بالتوكن (Polling كل 10 ثوانٍ) | لغات تانية غير العربي |

**قاعدة MVP Freeze:** بعد اعتماد شاشة المسح والحضور (المرحلة 8) يتوقف إضافة أي ميزات جديدة قبل الحدث، ويقتصر العمل على إصلاح الأخطاء فقط.
